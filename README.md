# 🎤 Voice Assistant (Time & Wikipedia)

A simple Voice Assistant built using **Python**, capable of telling the current time and fetching information from **Wikipedia** using voice commands.

---

## 📌 Features

- Voice recognition using microphone  
- Speaks responses using text-to-speech  
- Tells current time  
- Searches and reads summaries from Wikipedia  
- Continuous listening mode  
- Exit command support  

---

## 🛠️ Technologies Used

- Python  
- SpeechRecognition  
- Pyttsx3 (Text-to-Speech)  
- Wikipedia API  
- Datetime
